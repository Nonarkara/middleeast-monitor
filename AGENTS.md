# War Monitor maintenance

Read `STYLE.md` before visual work and follow https://github.com/Nonarkara/Non-Slop . Deliberate identity is protected; generic defaults are not. Preserve maps, tickers, charts, authored text and sponsor credits. Never collapse this file into a replacement application.

Check rendered breakpoints, keyboard paths, phone targets, source ages and actual tile images. Keep secrets in environment variables. Do not call a source scan a visual audit. A different reviewer checks deployed screens before completion. Done means attributed commit, push, deploy to this monitor's host and live verification.
