# War Monitor: deliberate operating choices

Audience: readers of the original dense public conflict tracker.
Job: locate events and inspect supporting status/news records.
Hierarchy: geographic evidence first, status/news instruments on request, detailed reference tables below.
Constraints: a monolithic authored application, public feeds, 320px phones and keyboard access.
Direction: retain the original dark watch desk, red event signal and dense domain material; do not replace it with a generic card dashboard.

All maps, tickers, charts, incident tags and earned text remain. News, Map, Status and More are explicit doors at every width. Map opens first. A compact drawer keeps supporting material readable without shrinking the map into a 220px strip. More opens secondary news widgets; the remaining reference tables stay below the map.

Category colours are semantic map keys. Light/dark maps remain actual usable tile services with attribution, not HTTP-200 API-key watermarks. No new decorative glows, gradients or rounded-card grid.

Test the deployed URL at CSS breakpoints and their neighbours, plus 1440/1024/390/320. Inspect actual pixels and exercise all four navigation doors and Escape. The central suite layout check is in the v3-global scripts directory. Independent review is required. Non-Slop: https://github.com/Nonarkara/Non-Slop (MIT).
